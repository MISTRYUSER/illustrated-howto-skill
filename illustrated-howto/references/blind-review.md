# 匿名评审

仅在用户要求匿名 judge、盲评或评分时使用，遵守 Agent 调用授权要求。

## 材料与隔离

- 使用独立上下文，不继承作者对话、版本历史、预期结论、旧分数。
- 用 A/B 等中性编号，提供完整正文、顺序一致的全部图示和实际版面；保留任务标题与必要来源，不透露作者和先后。
- 对照稿使用同一量表；仅让 Agent 读取材料，不编辑或操作生产系统。

## 默认量表

| 维度 | 分值 |
|---|---:|
| 目标具体 | 20 |
| 对象与前提 | 10 |
| 完成范围与停止边界 | 15 |
| 下一步明确 | 15 |
| 承诺与覆盖一致 | 10 |
| 意图清晰度小计 | 70 |
| 可执行性 | 20 |
| 图文对应与可读性 | 10 |
| 总分 | 100 |

用户提供其他标准时使用用户标准。要求短证据、具体卡点和建议。图多只有补齐导航或判读才加分；简短不自动得高分。停止边界不能掩盖目标未完成，未获准生产提交也不意味着必须实际发布才能写说明。

## 使用结果

- 保留不利结论，披露编号与文档映射。
- 不把不同轮次、不同 Agent 的分数当作严格提升幅度；单 Agent 评分不是客观认证或用户满意度。
- 版面证据不足时，可补正常窗口图，让原评审只复核受影响项，不提供目标分数。
- 不为冲高分改量表；是否继续修改或固化 Skill，根据真实缺口和用户意图决定。
