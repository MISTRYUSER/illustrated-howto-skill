# 云文档写入与版面核验

仅在线文档编辑时使用。工具接口以当前环境文档为准，不套用旧会话 API 或元素索引。

## 写入前

- 读取现有内容并检查并发编辑；只修改授权范围。
- 画布 DOM 可能只含当前区域，不能当作全文。使用支持的全文读取、复制或导出；核对首段、末段和关键章节。
- 先聚焦正文，避免复制目录、搜索框、标题栏或单个表格单元格。
- 确认平台支持的图片插入方式；上传完成不等于已插入正文。

## 实际故障与处理

| 现象 | 处理 |
|---|---|
| 正文继承标题，目录列出每段 | 导入前将插入段落设为正文；导入后检查真实样式，不能只看字号。 |
| 全选重置格式后图片缩小 | 优先局部修复；必要时逐图恢复合适尺寸并重查保存结果。 |
| 图片插在标题中 | 核实插入点及前后段落，不把滚动或未经验证的快捷键当定位。 |
| 多图粘贴中断 | 先查实际文档状态；分段插入、复用上传引用或保真压缩，避免重复导入。 |
| 只显示部分章节/图片 | 正常导航加载目标区域，区分虚拟化与丢失。 |
| 窄侧栏截断固定版心 | 在正常阅读窗口默认布局抽检，区分容器宽度与文档格式问题。 |

局部改动优先局部编辑。确需整体替换时，确认全文与读取版本一致，保留范围外内容和结构。

## 保存后

1. 确认图片实际呈现、文档保存完成。
2. 核对目录只列章节。
3. 检查连续入口图段与最复杂表单/发布段。
4. 重开后检查全文末段、图片尺寸和来源链接。
5. 按当前工具规范留交付截图，给用户直接可用的链接。

只检查、保存草稿、提交审核、正式发布、回滚分别报告，不互相代替。
